# Manuscript figures — canonical set

**This directory is the single source of truth for the figures in the manuscript.**
Files are named by their manuscript number (`Figure_1.png` … `Figure_5.png`,
`appendix/Figure_S1.png` …). Do not trust the many descriptively-named PNGs in
`ITT_Analysis/results/` — that is the working scratch directory and contains
multiple generations of each figure (e.g. several `Figure_4_*`). Always copy the
*current* render here under the clean numeric name.

Each file here is a copy of the live render produced by the script listed below
(which writes to `ITT_Analysis/results/` first). To refresh a figure: re-run its
script, then copy the output here under the canonical name.
